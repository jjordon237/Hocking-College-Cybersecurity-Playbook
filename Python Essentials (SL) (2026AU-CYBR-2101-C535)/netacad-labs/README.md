## Running a Script

Install Python 3, download or clone this repository, and open a terminal in the folder containing the script. Run:

```bash
python filename.py
```

Replace `filename.py` with the actual file name. Depending on your system, use `python3` or `py` instead of `python`. Follow any prompts displayed by the script.
