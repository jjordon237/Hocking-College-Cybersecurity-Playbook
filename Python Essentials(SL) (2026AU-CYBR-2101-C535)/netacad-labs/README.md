## Running a Lab

Install Python 3 and download or clone this repository. Open a terminal in the directory containing the script, then run:

```bash
python lab_filename.py
```

Replace `lab_filename.py` with the actual file name. Depending on your system, use `python3` or the Windows `py` launcher instead of `python`.

Check the individual lab's notes for input requirements or additional dependencies.
